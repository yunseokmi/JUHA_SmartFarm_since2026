01 // Background & Motivation

Origin & Why I Started

Before diving into microcontrollers and botany, I spent a year studying VEX robotics coding. Learning how code translates directly into physical motor movement and sensor triggers gave me a solid foundation in logic, loops, and debugging.

Transitioning from robotics to Arduino opened up a more open-ended world of hardware prototyping. My very first project was a basic temperature and humidity monitor using a DHT11 sensor and an LCD screen.

“Can a plant tell us when it actually needs water?”

Watching numbers fluctuate on a screen wasn't enough. I wanted to connect the sensor data to real biological needs—moving from simply reading numbers to building an automated system that responds intelligently to the environment.

Engineering Evolution

  • 01
    VEX Robotics (Year 1): Mastered sensor logic, conditional statements, and precise actuator control.
  • 02
    Arduino Foundation (Year 2): Breadboards, digital/analog pins, serial communication, and environmental sensing.
  • 03

Hardware Components

  • 🌱 Capacitive Soil Moisture Sensor v1.2: Corrosion-resistant analog sensor.
  • 🌡️ DHT22 Sensor: High-precision ambient temperature and humidity.
  • 💡 Photoresistor (LDR): Ambient light intensity measurement.
  • ⚡ Arduino Uno R3: Central microcontroller unit.
  • 🔌 1-Channel 5V Relay Module: Isolated switching for water pump.
  • 💧 Mini Submersible 3V-5V DC Pump: Low-flow irrigation delivery.

How the System Decides

  1. Measure: Analog signals sampled every 60 seconds.
  2. Decide: Compares moisture value against threshold constant.
  3. Water: Triggers relay for 3-second pulse if dry.
  4. Record: Prints timestamp and sensor state to Serial / SD.
  5. Improve: Adjusts delay to prevent root water-logging.
04 // Iteration & Testing

Build Log

BUILD LOG 004 // v0.2 October 2026

Testing Capacitive Soil Moisture Readings

Goal

Determine dry vs. saturated analog voltage thresholds for potting soil.

What I Tried

Placed sensor in completely dry soil mix, then poured measured 50ml increments of water, recording analog readings over 10 minutes.

What Happened

Initial dry value was ~780 (in 1023 scale), dropping to ~320 when saturated. However, readings drifted as water dispersed unevenly.

What I Changed

Added a 5-sample moving average filter in Arduino code to eliminate erratic single-point voltage spikes.

What I Learned

Raw sensor data is noisy; software filtering is just as critical as hardware placement.

Next Step

Test evaporation rate over 48 hours without watering.

// Moving average filter snippet int readSoilMoisture() { int total = 0; for(int i = 0; i < 5; i++) { total += analogRead(A0); delay(10); } return total / 5; }

06 // Empirical Research

Controlled Experiments

EXP-02 // RESEARCH PROTOCOL Active Trial

Does sensor orientation affect soil moisture reading stability?

Prediction: Vertical insertion will provide more consistent averaging across soil layers than diagonal insertion.

Variables: Independent: Insertion angle (0°, 45°, 90°). Dependent: Voltage variance over 24h.

Setup: 3 identical pots with identical soil compaction and moisture levels.

What Measured: Analog output sampled every 30 minutes for 24 hours.

Result: Vertical placement (90°) showed 14% less fluctuation during surface evaporation cycles.

Change Next Time: Test in organic vs mineral-heavy potting mixes.

08 // Firmware Architecture

Technical Notes & Code

The core logic relies on non-blocking delay checks to ensure sensor polling and pump safety intervals run smoothly without locking the microcontroller.

#define MOISTURE_PIN A0 #define RELAY_PIN 7 const int THRESHOLD = 300; // Dry soil cutoff void setup() { Serial.begin(9600); pinMode(RELAY_PIN, OUTPUT); digitalWrite(RELAY_PIN, HIGH); // Active LOW relay } void loop() { int moisture = analogRead(MOISTURE_PIN); if (moisture < THRESHOLD) { digitalWrite(RELAY_PIN, LOW); // Activate pump delay(3000); // 3-second watering pulse digitalWrite(RELAY_PIN, HIGH); // Stop pump delay(3600000); // Cooldown 1 hour } delay(60000); // Check every minute }

10 // Metacognition & Growth

Reflections

What was harder than expected?

Managing power distribution cleanly. When the water pump engaged, voltage drops caused the Arduino to reboot unexpectedly. Learning about decoupling capacitors and independent power rails solved this.

What changed my thinking?

I initially thought hardware engineering was mostly about building the physical machine. I now realize that interpreting sensor noise and writing stable logic is equally important.
