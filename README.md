# 🌱 Juha's Smart Grow Project

### From a simple Arduino sensor to understanding how plants grow.

**Arduino · Plant Science · Engineering · Sustainability**

---

## 🌿 Why I Started

My first Arduino project was a simple device that measured temperature and humidity.

At first, I was excited just to see the sensor work.

But then I started wondering:

> **Can a plant tell us when it actually needs water?**

That question became the starting point of this project.

As I continue developing the system, I want to understand not only how to build it, but also how sensors, data, and real plant observations can help me make better decisions.

---

## 🌱 Project Journey

**Measure → Decide → Water → Record → Improve → Explain**

### ✅ Stage 1 — My First Arduino Sensor

- Measured temperature and humidity
- Learned how sensors communicate with Arduino
- Started exploring environmental data

### 🔄 Stage 2 — Soil Moisture

- Measure soil moisture
- Compare dry and wet soil
- Calibrate the sensor
- Learn why sensor readings change

### ⏳ Stage 3 — Automatic Watering

- Connect a water pump
- Decide when watering is needed
- Build simple watering rules
- Add safety limits

### ⏳ Stage 4 — Light Measurement

- Measure light levels
- Observe changes in growing conditions
- Compare light with plant growth and water needs

### ⏳ Stage 5 — Real Plant Testing

- Test the system with a real plant
- Record sensor data
- Identify problems
- Improve the system
