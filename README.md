# 🌱 Juha's Smart Grow Project

> From a simple Arduino sensor to understanding how plants grow.

This project began with a simple question:

**Can a plant tell us when it actually needs water?**

I first learned Arduino by building a device that measured temperature and humidity.  
That made me curious about how sensor data could be used to make better decisions for real plants.

This repository records my learning process as I develop the project step by step.

---

## 🌿 Project Journey

**Measure → Decide → Water → Record → Improve → Explain**

### Stage 1 — My First Arduino Sensor
- Measured temperature and humidity
- Learned how sensors communicate with Arduino
- Began understanding how environmental data can be collected

### Stage 2 — Soil Moisture
- Measure soil moisture
- Compare dry and wet soil readings
- Calibrate the sensor

### Stage 3 — Automatic Watering
- Connect a water pump
- Decide when watering is needed
- Create simple watering rules

### Stage 4 — Light Measurement
- Measure light levels
- Compare light conditions with plant growth
- Observe how environmental conditions change over time

### Stage 5 — Real Plant Testing
- Test the system with a real plant
- Record sensor data
- Check whether watering decisions make sense
- Improve the system based on results
